# Milestone M11 Status

Status: COMPLETE.

## Scope

M11 implements the offline recovery and release kit defined by ADR-0002. It
adds deterministic FULL/STATE_ONLY workspace backup, fail-closed FULL restore,
and verifiable air-gapped Python release bundles. It does not modify canonical
`story.zip`, download models, add credentials or introduce cloud fallback.

## Implementation evidence

- SQLite state is captured with the online Backup API rather than copying a
  live database/WAL/SHM tuple. Integrity, foreign-key and migration authority
  are checked before publication.
- FULL backups bind the database, artifact/package metadata closure and regular
  published files in the runtime-owned `outputs/` tree by path, size and
  SHA-256. Pending files are excluded and symlinks fail closed.
- Backup ZIPs use fixed metadata and stable member ordering. Unchanged logical
  state produced byte-identical backups in integration tests.
- Restore uses the shared archive security/CRC/limit inspection, extracts to a
  same-parent staging directory, revalidates database and artifact bytes, and
  publishes only to an absent or empty destination.
- The release builder accepts only pre-provisioned wheels. It writes a
  hash-locked requirements file, CycloneDX 1.5 SBOM, external-runtime inventory,
  standard-library verifier and `--no-index --require-hashes` installer.
- CLI commands `audio-story backup` and `audio-story restore` return one
  machine-readable PASS/FAIL document with stable M11 error codes.

## Release remediation checkpoint

The release audit found that the original wheel did not contain the authoritative
SQL migrations and resolved migration paths relative to the source checkout.
The runtime now locates packaged migration resources first, retains an editable
checkout fallback, and fails closed when no migrations are present. Hatch copies
the eight byte-identical migration files into `audio_story/migrations/`.

The release builder rejects an application wheel whose packaged migration set
is missing or differs from the runtime authority. The previously implicit
`audio_story.artifacts` package also has an explicit package marker, and an
installed-wheel functional smoke now covers workspace initialization, Stage 1,
FULL backup, FULL restore and exact restored `story.zip` digest equality.
