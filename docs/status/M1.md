## Design

- `parser.py` scans exact byte lines and accepts only `===== <KIND>:<ID> <EDGE> =====` for `MODULE` or `OVERLAY` with `BEGIN`/`END`. It records one-based line spans and half-open byte spans.
- The parser rejects malformed, unmatched, nested, crossed and duplicate physical blocks. It extracts canonical rules, named gates, structural JSON registry declarations and output templates, with a unique canonical owner invariant.
- Structural registry values are decoded with `json.loads`; regular expressions only locate marker/headings and the fenced JSON payload, never parse JSON syntax.
- `registry.py` requires all 11 hot-path structural registries and exposes the alias-resolution entries.
- `dependency.py` validates alias types, missing targets, self-targets and alias cycles, then builds deterministic direct-reference edges and dependency closure.
- `capsule.py` uses `COMPACT_ROUTE_REGISTRY_JSON`, stage/profile entrypoints, owner modules and dependency closure. It excludes forbidden/dormant route material and keeps both compatibility/release overlays inactive unless the exact guard is supplied.
- Capsule JSON contains stage, profile, route, prompt digest, active blocks, source spans, ordered units, per-unit SHA-256/content, registry binding digests, dormant dependency records and a digest over the canonical preimage. JSON uses sorted keys, compact separators and UTF-8.
- The public API is limited to `parse_prompt`, `compile_capsule`, and `audio_mode_collision_finding`.

## Limits and risks

- Capsule snapshots cover the canonical `CREATE` route matrix required by the prompt. `REPAIR` and `RESUME` alter the route binding/digest and share the canonical active module map; later workflow behavior belongs to M3 and stage milestones.
- Unit dependency edges are static exact identifier references plus the canonical alias registry. Semantic conditional activation remains represented by route/overlay guards rather than executing prompt prose.
- The Stage 4 audio collision remains intentionally unresolved and must receive an approved canonical decision before M9.
- M2 deterministic artifact/schema/archive validation is explicitly absent.
