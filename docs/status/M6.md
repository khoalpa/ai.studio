# Milestone M6 Status

## Scope

This checkpoint implements the first M6 local image transaction slice only. It adds a backend-neutral
image adapter, deterministic mock PNG backend, loopback-only ComfyUI transport, OCR evidence port,
single-asset M3 transaction orchestration and deterministic postwrite image QA. Stage 2/3, video,
cloud services, model/workflow downloads and M7 are not implemented. `PCF001_STAGE4_AUDIO_MODE_DEFAULT_COLLISION` remains unresolved.

## M6-B production integration

The live ComfyUI, Vietnamese Tesseract and digest-bound Pillow/DejaVu Sans
checkpoints are now verified in their respective M6-B evidence files.
`generate_single_image()` optionally runs the production typography gate after
base PNG QA and before candidate registration. The final rendered PNG—not the
unmodified base—is registered, gated and committed. Its current gate set
contains both `IMAGE_QA_GATE` and `TYPOGRAPHY_GATE`, with base/font/text/final
digests and renderer identity persisted as deterministic evidence. Typography
failure closes the generation call, creates no binding and cannot advance
transaction progress. The integrated success/failure corpus passes with
`image_transaction.py` at 100% branch coverage. The full offline suite reports
300 passed, 2 optional smoke skips and 92.64% total branch coverage; Ruff,
mypy strict, canonical prompt SHA-256 and `git diff --check` pass.

## Limits

M6-B production validation is complete. The single orchestrated smoke ran
