# Milestone M10 Status

Status: COMPLETE.

## Scope

M10 implements the offline FFmpeg Video Studio handoff defined by
`VIDEO-STUDIO-SCENE-RENDER-HANDOFF-01`. It renders slideshow delivery artifacts
outside the authoritative Stage 4 archive. No media generator, network access,
model download or canonical-package mutation is used.

## Implementation evidence

- Strict Stage 4 intake verifies archive safety/CRC, manifest order and
  cardinality, member hashes/sizes, package digest, stage/purpose and the full
  M9 `video_prompts.json` source-binding validator.
- Strict SRT parsing rejects BOM, malformed numbering/timestamps, empty cues,
  overlap and non-positive durations. Planning requires one exact normalized
  cue per `story.script[]` item and checks the canonical total duration.
- The production runner can derive these cues with the accepted M9 timing
  algorithm without rewriting `story.json`.
- `AUTO`, `SCENE`, `ZONE` and `FIXED` are deterministic. SCENE validates exact
  ordinals/spans/oriented members and fails closed; ZONE uses the exact script
  zone and SRT interval; AUTO cannot infer scene boundaries.
- FFmpeg/FFprobe executables are explicit and digest-pinned. Subprocesses use
  argument arrays with `shell=False`, bounded output, timeout/cancellation
  cleanup and the existing one-heavy-job system lease.
- FFprobe gates exact stream cardinality, dimensions, `yuv420p`, CFR and
  duration. MP4, quality report and result manifest are atomically published
  and reopened by digest; the manifest binds every source/result digest.
