# Milestone M2 Status

## Outcome

Milestone M2 is complete. The packaged deterministic validator covers strict JSON and field order, versioned schema inventory, canonical serialization/digests, generic file-set contracts, basic PNG validation, ZIP security and deterministic result write/reopen. It performs no LLM, OCR, image-semantic or network operation and does not implement M3 persistence.

M1 was committed as `a75a0cbcec34fa49f066f9b1c1ffe8e0a115e0ea` after all quality gates passed. M0 commit `3fbbc58` remains in history.

## Implementation summary

- Strict JSON rejects invalid UTF-8, BOM, raw/NFC duplicate keys, comments/syntax errors, NaN/Infinity, trailing data, non-NFC engine output, excessive input size and excessive nesting.
- Ordered object representation supports root and nested field-order checks independently of schema validation.
- Nine artifact schemas are versioned. The result schema is implemented; the other eight are explicitly `NOT_VERIFIED` beyond version/phase checks because M2 does not invent incomplete Stage 1–4 semantic contracts.
- File-set validation checks normalized collisions, exact relative paths, required/forbidden files and derived caller-supplied counts.
- PNG validation checks signature, chunk boundaries and CRC, supported non-interlaced 8-bit modes, zlib decode/scanline size, dimensions, SHA-256 and parseable JSON `tEXt` metadata.
- ZIP validation rejects unsafe absolute/drive/UNC/traversal paths, normalized duplicates, directories, symlinks/special entries, encryption, CRC/decode failures and configurable expansion limits. Safe extraction never calls `extractall()`.
- Results bind exact artifact SHA-256, canonical prompt SHA-256 and M1 capsule digest. Ordered checks/findings have evidence digests.
- `result_digest` excludes `result_digest` and `result_self_reopen_status`, avoiding self-reference. No timestamp is emitted, so identical input/config produces identical bytes and digest. This resolves the attached request's truncated final sentence conservatively without inventing a timestamp contract.
