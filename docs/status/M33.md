# M33 Status — UI/UX foundation

Status: IN PROGRESS

## Accessibility and navigation foundation

- Added a keyboard skip link and a stable focus target for the main workspace.
- Navigation now exposes the current view with `aria-current`, preserves a
  hash deep-link, and moves focus to the newly opened view.
- The mobile navigation reports its expanded state, restores focus when it is
  dismissed, and closes consistently through the overlay or Escape key.
- The artifact inspector now behaves as a labelled modal dialog, traps focus,
  and returns focus to the row that opened it.
- Native dialogs have explicit accessible names and their validation messages
  use alert semantics.
- Unimplemented search, notification, and quick-check controls are disabled so
  they no longer advertise actions that cannot complete.
- Added high-visibility keyboard focus, forced-colour status boundaries, and
  reduced-motion-aware view navigation.
- Added shared semantic state, focus, control-size, radius, spacing, and motion
  tokens without changing runtime authority or API behavior.
- Normalized primary interactive controls to a 44 px minimum target and raised
  frequently used labels and body copy to a readable 14 px baseline.
- Contained long dialogs within the dynamic viewport. On narrow screens their
  action row remains visible, wraps predictably, and prioritizes the primary
  action without obscuring form content.
- Strengthened disabled and forced-colour states so availability does not rely
  on colour alone.
